Gatekeeper

A promotion gate for self-improving agent harnesses. An agent proposes edits to its own memory and instructions; the gate decides which edits are real improvements, using unseen tasks, verified outcomes, cost limits and automatic rollback.

Jump to the real Gemini run

Read this first. The first results below are from a simulated agent and a scripted proposer in a purpose-built toy game, averaged over 8 worlds. They test the gate logic against planted bad edits whose labels are known. They are not measurements of an LLM. The real-model path (Gemini adapter, cache, rate limiter) is implemented and tested against mocks.
